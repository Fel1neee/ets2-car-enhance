# Планы по докрутке физики `ets2_car_enhance` (v1.9+)

## 1. Реалистичный ESP (с потерей тяги при вмешательстве)
- **Текущее поведение (`physics_downforce.cpp`):** ESP прикладывает только чистый выравнивающий момент вокруг оси Y (`applyTorque`), не снижая скорость и не притормаживая машину — из-за этого выход из дуг ощущается слишком «стерильным».
- **Что сделать:** При активном вмешательстве ESP (`espActive == true` / пропорционально `appliedDecel`) добавлять лёгкую продольную тормозную силу (`-fwd`), имитирующую подтормаживание колеса и придушивание тяги реальной электроникой. Вынести коэффициент в конфиг (`esp_brake_drag`).

## 2. Клевок кузова при торможении (Brake Dive)
- **Текущее поведение (`physics_downforce.cpp`, Loop C):** Усиление ABS-тормоза прикладывается строго в центр масс (`applyCentralForce`), поэтому машина замедляется эффективно, но без клевка носа и ощущения переноса веса.
- **Что сделать:** Вместе с продольной тормозной силой прикладывать мягкий момент тангажа (`pitchTorque` вокруг локальной правой оси `rightX, rightZ`), пропорциональный `brake` и замедлению, чтобы кузов естественно клевал носом (и это передавалось на камеру салона / MotionCab). Вынести коэффициент в конфиг (`brake_dive`).

## 4. Упрощённая шинная модель (Pacejka-лайт + Круг Камма)
- **Прогрессивный срыв по `slipDeg`:**
  - `0–5°` — пиковый зацеп.
  - `6–11°` — мягкое скольжение на грани (чувствуется увод, есть окно для отлова рулём).
  - `12°+` — падение сцепления (резина срывается, нужно сбрасывать газ/угол).
- **Круг Камма + перенос веса (связка с клевком тормоза):**
  - Лёгкое подтормаживание в повороте загружает передок → улучшает вход (**trail braking**), перебор тормоза (`~100%`) срывает морду наружу.
  - Газ в пол в повороте на мощных авто ослабляет боковой зацеп задней оси → появляется контролируемый силовой занос (если ESP прикручен/выключен).

## 5. Температура шин и тормозов (этап 3 + мини-HUD)
- **Температура шин (`30–130°C`, оптимум `75–95°C`):**
  - Нагрев от скорости, угла увода (`slipDeg`), резких перекладок и тяги; охлаждение встречным потоком на прямой.
  - Холодные (`< 55°C`) и перегретые (`> 110°C`) шины теряют ~10–15% бокового/продольного сцепления.
- **Температура тормозов (`40–900°C`, Brake Fade):**
  - Резкий нагрев от `brake * speedKmh`, быстрое продувание на скорости при отпущенной педали.
  - При перегреве выше `~750°C` ABS-дожим (`extraBrakeG`) плавно снижается до ~40–60% от номинала (не в ноль, чтобы машина оставалась управляемой).
- **Технические правила реализации (по шагам):**
  - Нагрев/охлаждение считать через реальное `dt` (`QueryPerformanceCounter`), чтобы физика не зависела от FPS (60 vs 120+ fps).
  - Катить в 3 волны: сначала пункты `1 + 2 + 3` → затем `4` → затем `5`.
- **Мини-HUD (по желанию, включается в меню):**
  - Компактный индикатор температуры шин и тормозов в углу экрана (синий → зелёный → оранжевый → красный) для контроля и красивой картинки на видео/стримах.
